# Multi-agent control

Load when independent reasoning or maker/checker separation materially matters or is explicitly requested.

Give each actor a bounded assignment, the necessary inputs, isolated output or file ownership, and a clear handoff. For independent review, keep findings separate until submitted and avoid exposing the maker's reasoning or another reviewer's conclusions before the independent check. Supply the artifact and common acceptance criteria.

Name one integrator or final reviewer to reconcile results. State whether a finding blocks completion or is advisory. Missing required output or unresolved blocking disagreement stays incomplete; another actor must not silently replace its evidence.

Example: two reviewers independently check a draft against the same notes; an editor compares their submitted findings and blocks delivery on unresolved factual contradictions.

Add dependencies or a bounded repair loop only when needed. This guide assigns responsibilities in a prompt; it does not create agents or isolated storage. Current execution requires actual host support and authority.
